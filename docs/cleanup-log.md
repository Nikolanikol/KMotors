# Журнал зачистки проекта

Ведём с 26.11.2026. Правило: каждый шаг — отдельная ветка от `integration/cleanup`,
по завершении сливается в неё (`--no-ff`), на слитый коммит ставится тег
`cleanup/NN-имя`. В прод ничего не уходит, пока владелец явно не подтвердит push.

## Как откатиться

- Посмотреть точки: `git tag -l 'cleanup/*' -n1`
- Вернуть файлы к точке, не трогая историю: `git checkout cleanup/NN-имя -- <путь>`
- Откатить целый шаг: `git revert -m 1 <коммит слияния шага>` (шаги вливаются `--no-ff`,
  у коммита слияния два родителя)
- Состояние до всей зачистки: тег `cleanup/00-baseline`; старая структура CLAUDE.md
  отдельно — ветка `snapshot/claude-before` (коммит `241e958`)

## Ветки

| Ветка | Роль |
|---|---|
| `main` | прод; не трогаем, пока нет подтверждения push |
| `integration/cleanup` | локальный «sub-main»: сюда сливаются шаги зачистки |
| `docs/context-restructure` | шаг 01, уже слит по содержанию (коммиты внутри integration) |
| `snapshot/claude-before` | снимок со старым 223 КБ CLAUDE.md, для замера и отката |
