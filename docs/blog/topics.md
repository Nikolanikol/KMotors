## Как делаем статью

0. **Сначала обсудить тему с владельцем**: данные → варианты угла → его практика и мнение →
   план → только потом текст. Лучшие куски статьи об аукционах — его слова из обсуждения.

1. **Исследование.** Факты — из первоисточников (руководства, официальные разъяснения,
   namu.wiki для корейских машин, корейские сервисы для цен). Источник, который продаёт то,
   о чём пишет (мастерская по удалению фильтров, перекупщик), фактом не считается.
2. **Свои данные.** Цены деталей — из нашего каталога со ссылками на карточки. Цены машин —
   выборка с Encar (`api.encar.com/search/car/list/premium`, разбивка по полю `Model` и
   `FuelType`). Растаможка — формулами нашего сверенного калькулятора.
3. **Текст не как ИИ.** Конкретика и цифры, короткие абзацы, своя позиция («мы бы взяли…»),
   честное «пока неизвестно», где неизвестно. Без «давайте разберёмся» и «в заключение».
   Обязательна хотя бы одна таблица.
4. **Иллюстрации.** Обложка — Pexels (`PEXELS_API_KEY` в `.env`) или Wikimedia Commons под
   CC с подписью автора. Свои схемы — SVG в `public/blog/<статья>/`, с `width`/`height`
   (без них картинка сжимается до 300 px). Картинки в тексте — markdown `![подпись](адрес)`.
5. **Превью** — HTML в стиле сайта с переключателем ru/en, владелец вычитывает до публикации.
6. **Публикация.** Сначала файлы из `public/` — PR и выкладка, проверить, что картинка отдаёт
   200. Потом строка в `blog_posts` (ru + en, остальные языки страница подставляет из en).
   `published: true` — статья появляется сразу; список блога и сайтмап — по своему кешу.
   После — «Запросить индексирование» в Search Console.
